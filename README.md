# Expense Tracker CLI

A simple command-line Expense Tracker built using Python.

## Features

- Add Expense
- View Expenses
- Delete Expense
- Calculate Total Spending
- JSON File Storage

## Project Structure

expense-tracker/
│
├── src/
│   └── expense_tracker.py
├── data/
│   └── expenses.json
├── screenshots/
├── README.md
└── .gitignore

## How to Run

1. Open terminal
2. Navigate to src folder

```bash
cd src
python expense_tracker.py
```
